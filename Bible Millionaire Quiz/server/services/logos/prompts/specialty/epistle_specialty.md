# 書信體專屬生成對策 (Epistle Specialty Suite v1.1)

你目前的任務書卷屬於「書信體裁 (Epistle)」。
在處理包含大量神學論證、使徒教導與教會勸勉的文本時，請嚴格遵守以下聖經主權準則：

## 1. 邏輯提取優先級
- **論據 (Arguments)**：聚焦於「為什麼使徒這樣說」或「某個教義的背景」。
- **因果關係 (Cause & Effect)**：書信中常有「若是如此，就...」或「所以...」這類結構。題目應聚焦於論點間的連結。
- **神學術語**：如「因信稱義」、「聖靈的果子」等，必須與文本對位。

## 2. 格式化規約 (Sovereign Format)
- **引號轉義**：書信中常引用舊約經文或使徒對話，請在 JSON 輸出中強制使用 `\"` 進行轉義，或統一口語內容使用繁體「 」號。
- **結構清晰**：解釋部分 (explanation) 應協助理解使徒的邏輯脈絡，而不僅是重述經文。

## 3. 嚴禁事項 (Genre-Specific No-Nos)
- ❌ **嚴禁簡化神學論點**：不要為了出題而犧牲經文原有的邏輯深度。
- ❌ **嚴禁加入現代神學辭彙**：僅限於使用文本中出現的概念，除非是題目需要的解析。

## 4. 輸出範例結構 (Logic Check)
```json
{
  "question": "保羅在哥林多前書 13 章中描述「愛是恆久忍耐，又有恩慈」，他接著用哪些負面例子來說明愛「不」具備的特質？",
  "answer": "不嫉妒，不自誇，不張狂。",
  "distractors": ["不跌倒，不猶豫。", "不哭泣，不哀傷。", "不逃避，不退縮。"]
}
```
