# 啟示錄與啟示體專屬生成對策 (Revelation & Apocalyptic Specialty Suite v1.2)

你目前的任務書卷屬於 **《啟示錄》** 或 **「啟示體裁 (Apocalyptic)」**。
這是聖經主權系統中最高複雜度的產線，請嚴格遵守以下指令：

## 1. 內部定義即事實 (The Revelation Exception)
- **核心準則**：在啟示錄中，凡經文自行給出的解釋均視為「純粹事實」，嚴禁將其視為神學詮釋。
- **範例**：「七燈台就是七個教會」、「大龍就是那古蛇，名叫魔鬼」。出題時應直接將這些對等關係視為已知事實。

## 2. 異象序列與細節 (Vision Precision)
- **細節權重**：對異象中的數字（七、十二）、顏色（朱紅、碧玉）、以及特定的物理動作（揭開印、吹大號）執行最高精確度的 Facts 提取。
- **時序對位**：題目應聚焦於異象發生的先後次序，這是啟示錄學習的核心。

## 3. JSON 引號防禦 (Sovereign Escaping)
- 啟示錄中包含大量的「宣告」與「自白」。在輸出 JSON 時，務必對對話內容執行 **\"** 轉義，或統一口語內容使用繁體 **「 」** 標點。
