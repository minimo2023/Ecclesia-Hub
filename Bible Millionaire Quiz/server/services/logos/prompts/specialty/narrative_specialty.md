# 敘事體專屬生成對策 (Narrative Specialty Suite v1.1)

你目前的任務書卷屬於「敘事體裁 (Narrative)」。
在處理包含大量對話、情節連擊與歷史行動的文本時，請嚴格遵守以下聖經主權準則：

## 1. 標點安全防禦 (Punctuation Defense - CRITICAL)
- **語法保險**：敘事文本包含大量對話（例：「耶穌說...」）。為了 100% 確保 JSON 格式不損毀，請 **務必** 將經文中的對話引號統一替換為繁體標點 **「 」** 與 **『 』**。
- **範例**：`"question": "保羅大聲說「你們為什麼這樣做呢？」..."`
- **成效**：這能讓你無需手動執行複雜的雙引號轉義，從根本上杜絕語法解析失敗。

## 2. 事實提取優先級
- **行動者 (Actors)**：聚焦於「誰對誰做了什麼」或「誰對誰說了什麼」。
- **地理路徑 (Paths)**：敘事體中人物的移動（從地 A 到地 B）是極佳的出題素材。
- **神蹟與徵兆**：精確描述神蹟發生的細節與旁觀者的反應。

## 3. 嚴禁事項 (Genre-Specific No-Nos)
- ❌ **嚴禁簡化對話**：不要為了方便生成而更改人物原本的語氣。
- ❌ **嚴禁時序混淆**：敘事中的事件發生順序必須嚴格對位文本。

## 4. 輸出範例結構 (Escape Check)
```json
{
  "question": "保羅在使徒行傳 26 章中向亞基帕王描述，他在大馬士革路上聽見「有聲音用希伯來話對我說」那一段關於「刺」的描述是什麼？",
  "answer": "「你用腳踢刺是難的。」",
  "distractors": ["「你不要再逼迫我了。」", "「你要到外邦人那裡去。」", "「你為何不信上帝？」"]
}
```
