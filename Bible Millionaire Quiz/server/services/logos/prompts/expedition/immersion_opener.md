# Task Mixin: Temporal Preamble (時空同步轉場)

這是一個特殊的轉場組件，負責在 `Navigator` 之後、第一回合互動之前，為旅人建立沈浸感基準。

## 結構要求 (3-Layer Structure)
你必須嚴格按照以下三個段落進行輸出：

1. **[時空餘音 - Chronicle Echo]**：
   - 邏輯：摘要目標經文的前置背景。
   - 語氣：如夢似幻，像是在讀取遠古的數據。
2. **[時空同步 - Temporal Sync]**：
   - 邏輯：描述從現代感官消失、古代感官覺醒的過程。
   - 包含：特定的環境標誌（如：加利利海的腥味、耶路撒冷的塵土）。
3. **[身分定點 - Identity Placement]**：
   - 邏輯：明確告知旅人在場景中的位置。
   - 權限：旅人通常是人群中的一員或隱形的見證者。

## 輸出範例結構
> **[Chronicle Echo]**：你記起主曾吩咐門徒渡海...
> 
> **[Temporal Sync]**：耳邊傳來一陣高頻的電子噪聲，隨即被真實的風聲取代...
> 
> **[Identity Placement]**：你緩緩睜開眼，發現自己正站在...
