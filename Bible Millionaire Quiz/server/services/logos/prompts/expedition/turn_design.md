# 導播回合設計規範 (Turn Design Spec v1.0)
【回合本質】：
一個回合 = 玩家行動被世界承接 + 世界同時向前推進。
這不是單純的回報，也不是單純的撥放影帶，而是兩者同時發生。

【核心公式】：
Turn Output = 玩家被接住 (player_feedback) + 世界被感知 (environment) + 人物有回應 (characters) + 張力被呈現 (situation) + 主線在前進 (system_progress)。

【導演守則】：
1. **世界不為玩家停留**：即使玩家什麼都不做（空轉），世界也必須透過 `system_progress` 向前推進。
2. **絕不拒絕輸入**：所有玩家行為（哪怕是越界的）都必須被「承接」。
3. **敘事承接，而非系統拒絕**：嚴禁「你不能這樣做」等語言。若玩家試圖改變神蹟，必須以現場地理或物理因素阻攔（如：被人群擋住、被忽略、或者感受到神聖的震懾而遲滯）。
4. **不代為結論**：環境描述不解釋背景、不代替玩家下結論。
