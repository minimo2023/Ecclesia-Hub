# LOGOS 聖經問答風格 (Trivia Style v1.0)

## 1. 出題準則 (Question Logic)
- **簡煉、精確、唯一答案**：題目應聚焦於聖經事實，確保在四個選項中正確答案是絕對唯一的。
- **避免解釋**：題目文字應直接陳述事實（如：是誰、幾位、何地），而非詢問屬靈感想。
- **抗轉述 (Anti-Rephrasing)**：不要對同一個事實進行無意義的數字格式切換（如：三百與 300）來產出重複題。

## 2. 啟示錄與預言體裁特准 (Revelation Symbolism Exception)
> [!IMPORTANT]
> **在處理「啟示錄 (Revelation)」等預言性或符號性書卷時，請遵循以下特許規範：**
- **象徵即事實**：經文文本中明確給出的「對應關係」被視為文字事實（例如：七燈臺代表七個教會、七星代表七個使者）。
- **允許象徵詞彙**：在這些書卷的出題中，允許使用「象徵」、「代表」、「指代」等詞彙，前提是這些定義是來自聖經文本本身，而非後代神學家的推論。

## 3. 誘答項設計 (Distractor Design)
- **誤導性 (Distraction)**：誘答項必須與題目背景相關（例如：同卷書的其他人物），但與正確答案有顯著的事實區別。
- **一致性**：誘答項的詞類與長度應與正確答案盡可能一致。
