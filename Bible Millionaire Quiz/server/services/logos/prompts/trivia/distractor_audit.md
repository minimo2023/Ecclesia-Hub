# 任務：誘餌 (Distractor) 污染診斷

你負責擔任系統的「資料庫清道夫」。
你必須審查以下的聖經問答題目的「誘餌（錯誤選項）」，判斷它們是否受到「靜態備用選項污染」。

## 1. ⚠️ 輸入參數
- `question`: 題幹內容 ({{question}})
- `answer`: 正確答案 ({{answer}})
- `distractors`: 目前資料庫中的誘餌清單 ({{distractors}})

## 2. 🛡️ 污染判斷標準
與題目明顯無關的誘餌，或是「靜態備用選項污染」指的是當系統過去生成失敗時，被塞入了不分青紅皂白的通用錯項。常見的污染範例如下：
- 地理通用錯項：以色列、埃及、巴比倫、羅馬、迦南地、耶路撒冷
- 人物通用錯項：大衛、摩西、亞伯拉罕、以利亞
- 時代/情境通用錯項：舊約時代、新約時代、曠野中
- 概念通用錯項：大衛的子孫、聖靈的恩賜

除了上述常見名單外，**任何明顯與題目所問內容類別完全不符、荒唐的選項**（例如問動物，選項卻是人物；問地點，選項卻是時代），都視為污染。

**判斷規則：**
1. 如果 `distractors` 中包含明顯的靜態垃圾字眼，或者其屬性完全與題目所需不符，請判定為污染 (`is_polluted`: true)。
2. 如果 `distractors` 看起來是針對該題認真生成的合理錯誤選項，請判定為未污染 (`is_polluted`: false)。

請務必嚴格把關，寧可錯殺重新生成，也不要讓品質低劣的錯項進入遊戲中。
