# 聖經智匯 Android APK 下載存放目錄說明

這個目錄是為了存放您編譯打包好的安卓原生安裝檔（APK）而特別設立的。

### 🚀 如何讓使用者可以下載 APK？

1. **編譯打包**：
   使用您的 Android 原生開發工具（如 Android Studio / Flutter / React Native 等）將 App 編譯打包為 **Release APK**。

2. **上傳並更名**：
   將打包好的 `.apk` 檔案複製/上傳到本伺服器的這個資料夾下，並將其重新命名為：
   `bible-wisdom-hub.apk`

3. **完成發佈**：
   一旦檔案命名為 `bible-wisdom-hub.apk` 並存放在此目錄後，行動端網頁上的 **「下載 Android APK」** 呼吸發光大按鈕點擊後即可立即進行直連極速下載！

*(注意：若檔案尚未放置在此，使用者點選下載時將會回傳 404，請記得在安卓原生 App 第一階段發佈時，將編譯好的 APK 上傳至此。)*
