# 主日服事排班工具

這是一個可共同編輯的網頁版排班工具。多人開同一個網址時，修改會即時同步，資料會儲存在後端 SQLite 資料庫 `schedule.db`。

## 本機執行

```powershell
npm start
```

預設網址：

```text
http://localhost:3000
```

如果 3000 已被其他程式使用，可以改用其他埠：

```powershell
$env:PORT=3100; npm start
```

同一個網路中的其他人可以用這台電腦的區網 IP 連線，例如：

```text
http://你的電腦IP:3100
```

## 存檔資料庫

- 目前排班資料存在 `schedule.db`
- 每次儲存會寫入 `schedules` 表
- 每次儲存也會在 `schedule_revisions` 表保留一筆歷史紀錄
- `schedule.db` 已加入 `.gitignore`，避免把真實排班資料送進版本控制

## 功能

- 大堂和兒主分頁輸入
- 服事人員清單可新增、編輯、刪除
- 人員資料包含姓名、服事類別、可複選的服事細項
- 大堂可用半年產生日期，例如 2027 年上半年
- 兒主可用季度產生日期，例如 2027 年第一季
- 合併輸出頁會把大堂和兒主合併成同一張表
- 同一天同一人跨大堂和兒主會提醒
- 備註可手動輸入
- 可匯出 CSV、列印
